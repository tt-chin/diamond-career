# ダイヤの軌跡

高校入学からドラフト、日本プロ、海外挑戦、引退までを短時間で遊ぶ日本野球人生シミュレーターです。

## 現在実装されている内容

- 投手、捕手、内野手、外野手
- Seed付きサイコロと能力への自由配分
- 高校3年間と大会結果
- ドラフト、本指名、育成指名、指名漏れ
- 大学・社会人からの再挑戦
- 日本プロの一軍・二軍、成績、年俸、表彰
- 架空30球団からの海外オファー、マイナー、メジャー
- 国際大会の日本代表イベント
- 故障、移籍、戦力外、引退
- 年度別・リーグ別通算・国際大会成績
- ブラウザー内の自動保存
- ページ分割なしの単一ページ構成

## ローカル確認

静的サイトのため、任意のHTTPサーバーでリポジトリのルートを配信してください。`file://`ではなくHTTP経由で開くことを推奨します。

ゲームエンジンのテスト：

```sh
node tests/engine.test.mjs
```

## GitHub Pages

`.github/workflows/pages.yml`が`main`または`master`へのpushを検知して自動公開します。GitHubリポジトリのSettings → Pagesで、Sourceを「GitHub Actions」に設定してください。
