# 06 テスト・バランス設計書

## 1. 文書情報

- バージョン：v0.2（シンプル版）
- 目的：短く遊べて、進行不能や極端な偏りがないことを確認する。

## 2. 品質目標

- 同じSeedと選択で同じ結果になる。
- すべての有効な選択経路が引退または結果画面へ到達する。
- 能力、疲労、成績、年俸に不正値が出ない。
- 1プレイを20〜30分程度で終えられる。
- 投手と野手のどちらでも楽しめる。
- 選択の効果がランダム結果に完全には埋もれない。

## 3. 単体テスト

- Seed付き乱数が同じ列を生成する
- 能力と疲労が0〜100を超えない
- 同じSeedと選手条件で能力上限が一致する
- 異なるSeedで能力上限の組み合わせが変化する
- 成長後の能力値が個別上限を超えない
- 打率・防御率が正しく計算される
- AVG、OBP、SLG、OPS、ERA、WHIPが正しく計算される
- 年度別・リーグ別通算・国際大会表の列と順序が元サイト仕様と一致する
- 打数0、投球回0でもエラーにならない
- 年齢と年度が正しく増える
- 高校3年後にドラフトへ進む
- 引退後にゲームを進められない
- 保存後に同じ状態を読み込める

## 4. 通しテスト

最低限、次のキャリアを自動実行する。

- 高卒ドラフトから日本プロで引退
- 育成指名から一軍昇格
- 指名漏れから大学・社会人経由でプロ入り
- 戦力外から再契約
- 海外挑戦からメジャー昇格
- 海外挑戦失敗から日本復帰
- 重傷による早期引退

各経路で結果画面まで到達することを確認する。

## 5. 固定Seedテスト

代表的なSeedと選択列を保存し、最終状態の要約を比較する。

比較対象：

- 最終年齢と所属
- 能力
- 通算主要成績
- 年俸
- 特性と受賞歴
- キャリア称号

文言だけの変更でテストが壊れないよう、本文全文は比較しない。

## 6. 自動シミュレーション

UIを使わず、次の簡単な選択方針でキャリアを大量実行する。

- バランス型
- 能力特化型
- 休養優先型
- 海外挑戦型
- ランダム型

実行数：

- 開発中：100回
- 大きな変更後：1,000回
- 公開前：10,000回

## 7. 確認する指標

- ドラフト本指名率
- 育成指名率
- 最終プロ入り率
- 一軍到達率
- 海外到達率
- 日本代表選出率
- 平均・中央値の現役年数
- 引退年齢
- 重傷による早期引退率
- 投手・野手別の通算主要成績
- 野手の年度別・リーグ別通算OPS
- キャリア称号の出現率

## 8. 初期目標範囲

数値はゲームとしての仮説であり、後から調整する。

| 指標 | 暫定目標 |
|---|---:|
| 高卒本指名 | 20〜35% |
| 育成指名 | 10〜20% |
| 再挑戦を含む最終プロ入り | 50〜70% |
| プロ入り後の一軍到達 | 50〜75% |
| 一軍選手の海外到達 | 5〜15% |
| プロ選手の代表選出 | 10〜25% |
| プロ現役年数中央値 | 7〜11年 |
| 30歳未満の重傷引退 | 1〜5% |
| 伝説級称号 | 1〜3% |

## 9. シンプルさのテスト

機能の正しさだけでなく、複雑さも検証する。

- 初回開始まで1分以内
- 通常場面の選択肢は4個以下
- 1画面に同時表示する主要数値は8個以下
- 通常の選択に必要な説明は3行以内
- 制度用語を知らなくても選択の意味が分かる
- 1プレイの操作回数と所要時間を記録する

テストプレイヤーが頻繁に詳細説明を求める項目は、仕様を簡略化するか文言を修正する。

## 10. ポジション差

投手、捕手、内野手、外野手について、プロ入り率、現役年数、最高評価を比較する。

結果を完全一致させる必要はないが、特定ポジションの成功率が他より20%以上低い場合は調査する（暫定）。

## 11. UIテスト

対象：iOS Safari、Android Chrome、Windows Chrome・Edge、macOS Safari。

主な確認：

- 320px幅でも選択肢を押せる
- 固定ステータスが本文を隠さない
- 長い日本語でカードが崩れない
- 折りたたみ能力・成績・履歴が操作できる
- 再読み込み後に続行できる
- 結果画像が欠けない
- 連打でターンが二重進行しない
- サイコロ割当直後に能力値と進捗バーが確定前表示へ更新される
- 配分欄の能力名、進捗バー、現在値・上限値が狭い画面でも崩れない
- キャリアログの初期位置が最新で、上方向へ全履歴をスクロールできる

## 12. 保存テスト

- 選択直後の再読み込み
- 破損JSONからバックアップ復元
- 古い保存バージョンの検出
- localStorage無効時の警告
- 複数タブでの競合警告
- オフラインでの続行

## 13. 公開判定

- 重大な進行不能が0件
- 固定Seedテスト成功
- 100回連続で全キャリアが終了
- 公開前10,000回の自動実行完了
- 能力・成績の不正値0件
- AVG、OBP、SLG、OPS、ERA、WHIPの非数・無限値0件
- 主要スマートフォンで致命的な表示崩れなし
- テストプレイ中央値が目標時間内
- 第三者コード・文章・画像の無断利用なし

## 14. バランス変更手順

1. 問題となる指標を確認
2. 変更する設定値を1〜2個に絞る
3. 固定Seedテスト
4. 1,000回シミュレーションで前後比較
5. 投手・野手への副作用確認
6. 変更理由を記録

## 15. 暫定値

- 各目標範囲
- 自動実行回数
- プレイ時間20〜30分
- 主要数値8個以下、説明3行以内
