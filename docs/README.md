# 日本野球人生シミュレーター 設計文書

このディレクトリは、日本の高校野球からプロ入り、海外挑戦、引退までを扱うブラウザーゲームの設計文書を管理する。

## 設計方針

- 既存の YaKyoLife は、育成・選択・Seed・年次進行・結果共有という体験設計の参考に限定する。
- 元サイトのコード、文章、イベント表、確率、データ構造、固有名称、画像は流用しない。
- 日本の野球制度を題材に、ゲームルール、数式、データ、画面を独自設計する。
- 初版では実装開始に必要な境界を定め、細かな数値はシミュレーション結果を見て調整する。
- 実在の大会制度は参考にするが、学校・球団・ロゴは原則として架空とする。

## v0.2の簡略化方針

- ページ分割と画面遷移は行わず、すべてを1つのHTMLページ内で表示する。
- 開始・進行・引退結果は、同じページの表示モードとして切り替える。
- 能力は投手4項目、野手5項目に限定する。
- 高校は年4ターン、プロは年3ターンで進行する。
- 大学・社会人、FA、トレード、代表、海外制度は短いイベントへ統合する。
- 制度の精密な再現より、20〜30分でキャリアを完走できるテンポを優先する。

## 確定した主要仕様

- 育成は6面サイコロ4個を振り、各サイコロを好きな能力へ自由配分する。
- 守備区分は投手・捕手・内野手・外野手とする。
- 日本は架空12球団、海外は架空30球団（2リーグ各15球団）とする。
- 大学は最大4ターン、社会人は最大3ターンとする。
- 国内の学校・球団は架空名称、国際大会は詳細名称を表示する。
- 日本のドラフトとトレードは自動決定、FAと海外契約は複数候補から選択する。
- 成績表示の列と並び順は、元サイトの公開版と一致させる。
