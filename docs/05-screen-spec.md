# 05 画面設計書

## 1. 文書情報

- バージョン：v0.2（シンプル版）
- 方針：ページ分割や別URLへの画面遷移を使わず、すべてを1つのHTMLページ内に実装する。

## 2. デザイン方針

- 最大幅640pxのモバイルファースト設計
- 明るい背景、深緑または濃紺、黄色のアクセント
- カードと大きな選択ボタン
- スコアボード風の数字表示
- 元サイトや参考サイトのコード、ロゴ、配色、画像はコピーしない
- 下部の5画面ナビゲーションは採用しない

## 3. 単一ページ構成

`index.html`だけを入口とし、ルーティング、ページネーション、別ページへの遷移は使用しない。

同じページ内に次の表示モードを持つ。

- 開始モード：新規開始、再開、選手作成
- ゲームモード：状況、イベント、育成、能力、成績、履歴、選択
- 結果モード：引退結果、通算成績、キャリア履歴、再挑戦

各モードは同じルート要素内で差し替える。能力、成績、履歴、設定は別ページにせず、折りたたみ領域またはダイアログで表示する。URLはゲーム中も変更しない。

## 4. 開始モード

### 表示

- タイトルと短い説明
- 選手名
- 投手・捕手・内野手・外野手
- 利き腕
- 選手タイプ
- Seed
- 「キャリア開始」ボタン
- 「続きから」ボタン（保存がある場合）

入力項目を1ページに収め、複数ステップのウィザードにはしない。

選手名は最大12文字とし、未入力の場合は日本人名を自動生成する。

## 5. ゲームモード

```text
┌ 固定ステータス ─────────┐
│ 選手名　所属             │
│ 17歳 / 高3夏 / 総合 58   │
│ 年俸 0 / 疲労 42         │
└──────────────────┘

▼ 能力を見る　▼ 成績を見る

┌ キャリアログ ──────────┐
│ 大会結果、成長、契約など │
│ 新しい結果ほど下に追加   │
└──────────────────┘

┌ 現在のイベント ─────────┐
│ 監督から重点練習を…      │
│ [球速を磨く]             │
│ [制球を磨く]             │
│ [休養する]               │
└──────────────────┘
```

### 5.1 固定ステータス

- 選手名、所属
- 年齢、年度、現在時期
- 総合力
- 疲労
- 年俸（プロ入り後）
- 一軍・二軍、マイナー・メジャー

高さを抑え、本文表示領域を狭めすぎない。

### 5.2 折りたたみ情報

#### 能力

投手4項目または野手5項目、特性、調子を表示する。能力値は`現在値 / 上限値`で表示する。育成時は4個のサイコロを表示し、各サイコロを能力へ割り当てられるようにする。

#### 成績

現在年と通算成績を表示する。列名と並び順は元サイトの公開版と完全一致させる。

- 野手年度別：`年 / 齢 / 球団 / G / PA / AVG / OBP / SLG / OPS / H / HR / RBI / SB / DEF`
- 投手年度別：`年 / 齢 / 球団 / G / IP / W / L / SV / HLD / SO / BB / ERA / WHIP`
- 野手リーグ別通算：`League / Yrs / G / PA / AVG / OBP / SLG / OPS / H / HR / RBI / SB / DEF`
- 投手リーグ別通算：`League / Yrs / G / IP / W / L / SV / HLD / SO / BB / ERA / WHIP`
- 国際大会・野手：`G / PA / AVG / H / HR / RBI`
- 国際大会・投手：`G / IP / W / SV / SO / ERA`

横長の表は横スクロール可能にする。

#### 履歴

年ごとに折りたたみ、重要イベントだけを絞り込めるようにする。

### 5.3 キャリアログ

- 大会結果
- 能力変化
- 年間成績
- ドラフト、昇格、移籍
- 故障、覚醒、代表
- 契約更改

ログ領域は縦スクロール式とし、全履歴を保持する。初期表示時は最新結果が見える位置まで自動スクロールし、上へスクロールすると過去の記録を確認できる。最新結果は重要色で目立たせる。

### 5.4 選択肢

- 原則2〜4個
- ボタン全体をタップ可能
- 短い結果予想を`small`表示可能
- 重大な進路選択だけ確認ダイアログを出す
- 選択処理中は連打を無効化

### 5.5 サイコロ育成

育成ターンでは4個のサイコロと能力行を表示する。能力行は「能力・特性」と同じく、名称、進捗バー、`現在値 / 上限値`、割当ボタンの順に表示する。開始時は1個目を自動選択し、能力へ割り当てると能力値と進捗バーへ増加分を即時反映して、次の未使用サイコロを自動選択する。同じ能力へ複数個を割り当てられる。上限到達済みの能力は選択不可にする。

```text
サイコロ：6 / 4 / 3 / 1
球速  45/72  [割当]
制球  38/61  [割当]
変化  41/68  [割当]
[決定]
```

## 6. 重要イベント表示

ドラフト、海外挑戦、戦力外、引退は通常カードより大きく表示する。

- 状況説明
- 主な条件またはリスク
- 2〜3個の選択肢
- 戻せない選択である旨

制度の詳細説明は表示せず、ゲーム上の意味だけを伝える。

## 7. 結果モード

### 表示

- 選手名とキャリア称号
- 現役期間、最終所属
- 投手または野手の通算主要成績
- 最高年俸、生涯年俸
- タイトル、代表歴
- 重要なキャリア年表
- Seed、ゲームバージョン

### 操作

- 結果画像を生成
- 画像を保存・共有
- 同じSeedで再挑戦
- 新しいSeedで開始
- 年度別成績を開く

## 8. 設定ダイアログ

- 文字サイズ
- アニメーション低減
- 最初からやり直す
- セーブ削除
- バージョン、クレジット、権利表記

設定項目を増やしすぎない。データ削除は確認を2段階にする。

## 9. レスポンシブ

- 〜419px：余白を狭くし、ボタンは全幅
- 420〜640px：標準表示
- 641px〜：中央640pxに配置
- `safe-area-inset-bottom`に対応
- 横画面でも操作部分を隠さない

## 10. アクセシビリティ

- 本文16px相当
- タップ領域44×44px以上
- 色だけで上昇・低下を伝えない
- キーボード操作とフォーカス表示
- `prefers-reduced-motion`対応
- 成績表に見出しを設定
- 結果画像と同内容をテキストでも表示

## 11. エラーと保存表示

- 自動保存は通常通知しない
- 保存失敗時だけ画面上部に警告
- 破損時はバックアップ復元を案内
- オフラインでもゲームを継続可能
- 共有機能だけ利用不能として説明する

## 12. 暫定値

- 最大幅640px
- 配色とフォント
- ステータス領域の固定方法
- ログの自動折りたたみ件数

## 13. 継続検討事項

- サイコロをアニメーション表示するか
- 能力を数値とバーの両方で表示するか
- 結果画像を縦長にするか正方形にするか
- ダークテーマを後から追加するか
