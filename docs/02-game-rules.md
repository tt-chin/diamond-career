# 02 ゲームルール仕様書

## 1. 文書情報

- バージョン：v0.2（シンプル版）
- 原則：複雑な制度ではなく、少ない能力と選択肢でキャリアを表現する。

## 2. 1ターンの流れ

```text
状況・イベント表示
  ↓
2〜4個の選択肢から選ぶ
  ↓
Seed付き乱数で結果判定
  ↓
能力・成績・所属を更新
  ↓
結果ログを表示
```

ゲーム内の全ランダム判定は専用のSeed付き乱数を使う。

## 3. 時間の進行

### 高校

1年を4ターンにする。

- 春：育成
- 夏：大会
- 秋：育成・大会
- 冬：育成・進路イベント

高校3年の最後にドラフト判定を行う。

### プロ

1年を3ターンにする。

- 春：キャンプ・育成
- シーズン：成績とイベント
- 冬：契約更改・移籍・進路

一軍・二軍の細かな日程は管理しない。

## 4. 能力値

能力は0〜100の範囲で表すが、実際に成長できる上限は選手・能力ごとに異なる。

能力上限はSeed、守備区分、選手タイプ、能力名から決定する。同じ条件とSeedでは常に同じ上限になり、異なるSeedでは上限の組み合わせが変化する。画面には`現在値 / 上限値`で表示する。

### 投手

- 体力
- 球速
- 制球
- 変化球

### 野手（捕手を含む）

- 体力
- ミート
- 長打
- 走力
- 守備

捕手は能力を追加せず、守備評価に捕手補正を付ける。詳細な肩力、選球眼、守備範囲、配球などは内部補正または特性で表現する。

## 5. 総合力

総合力は能力の加重平均から計算し、0〜100で表示する。守備位置と役割によって重みを変える。

総合力は分かりやすい目安であり、試合結果を単独で決めない。

## 6. 育成

各育成ターンで6面サイコロを4個振り、各サイコロを好きな能力へ割り当てる。同じ能力へ複数個を割り当てられる。1個目は最初から選択状態とし、能力へ割り当てるたびに次の未使用サイコロを自動選択する。疲労やイベントにより利用可能な個数が変化する場合がある。

主な選択肢：

- バランス練習：複数能力が少し上昇
- 専門練習：1能力が大きく上昇
- 実戦練習：能力と評価が上昇
- 休養：疲労を回復

能力が高いほど上昇しにくくする。細かな指導者・施設係数は作らず、イベント補正へ統合する。

## 7. 体力と疲労

- 体力：選手の基礎能力
- 疲労：0〜100の短期状態

練習と試合で疲労が増え、休養で減る。疲労が高いと成長効率が落ち、故障率が上がる。80以上で警告を出す（暫定）。

## 8. 試合と成績

試合は個別操作せず、大会またはシーズン単位で成績を生成する。

### 野手の年度別成績

`年 / 齢 / 球団 / G / PA / AVG / OBP / SLG / OPS / H / HR / RBI / SB / DEF`

### 投手の年度別成績

`年 / 齢 / 球団 / G / IP / W / L / SV / HLD / SO / BB / ERA / WHIP`

### 野手のリーグ別通算成績

`League / Yrs / G / PA / AVG / OBP / SLG / OPS / H / HR / RBI / SB / DEF`

### 投手のリーグ別通算成績

`League / Yrs / G / IP / W / L / SV / HLD / SO / BB / ERA / WHIP`

列名、列順、表示対象を元サイトの公開版と一致させる。

国際大会の通算表は元サイト同様に項目を絞る。

- 野手：`G / PA / AVG / H / HR / RBI`
- 投手：`G / IP / W / SV / SO / ERA`

## 9. 高校大会

大会結果は、総合力、調子、学校補正、Seed付き乱数から判定する。

結果区分：

- 予選敗退
- 地区上位
- 全国大会出場
- 全国大会上位
- 全国優勝

大会結果は能力上昇、スカウト評価、特殊イベントに影響する。

## 10. ドラフト

指名評価は、能力、高校実績、将来性、Seed付き乱数から算出する。

結果：

- 上位指名
- 本指名
- 育成指名
- 指名漏れ

指名漏れ時は「大学で再挑戦」「社会人で再挑戦」「野球を終える」を表示する。大学・社会人は1年1ターン、最大2〜4回の簡略イベントとする。

## 11. プロ生活

シーズン開始時に一軍または二軍を判定する。判定要素は総合力、前年成績、年齢、故障だけに絞る。

シーズン中に昇格・降格イベントが発生することがあるが、登録日数は管理しない。

## 12. 年俸

前年年俸とシーズン活躍度から翌年年俸を決める。

```text
翌年年俸 = 前年年俸 × 活躍補正
```

タイトルや代表選出で追加補正する。契約金、出来高、税金、複雑な契約年数は扱わない。

## 13. 特別イベント

- 覚醒：能力が大きく上昇
- スランプ：一定期間成績補正が低下
- 軽傷：その年の成績が低下
- 重傷：長期離脱、能力低下の可能性
- トレード：所属球団が変わる
- 戦力外：再契約か引退を選ぶ
- 日本代表：条件達成時に大会へ参加
- 海外挑戦：条件達成時に挑戦を選べる

制度を細分化せず、それぞれ1〜2回の選択イベントとして扱う。

国際大会は、条件に応じて「U-18ワールドカップ」「プレミア12」「ワールド・ベースボール・クラシック」「オリンピック」の詳細名称を表示する。開催条件はマスターデータで変更可能にする。

## 14. 特性

特性は少数に限定し、効果を分かりやすくする。

- 努力家：育成効果上昇
- 天才：能力上限付近でも成長しやすい
- 鉄人：故障率低下
- ガラスの身体：故障率上昇
- 大舞台：重要大会で好成績
- 晩成：年齢が上がっても成長
- 人気者：年俸・代表イベントに小補正

同時保有数には上限を設ける。

## 15. 海外挑戦

一定の年齢、能力、実績を満たすと「海外挑戦」イベントが出現する。

選択肢：

- 日本に残る
- 海外へ挑戦する

海外は「マイナー」と「メジャー」の2状態だけにする。架空30球団を2リーグ各15球団に分け、球団特性は強豪・平均・再建、および育成力の高・中・低に限定する。FA年数、ポスティング承認、契約条項は内部条件へまとめ、画面には出さない。

日本のドラフト指名球団とトレード先は自動決定する。FAと海外挑戦では、最大3件のオファーから年俸、開始レベル、想定起用を比較して選択する。

## 16. 引退

年齢、能力低下、故障、契約状況から引退候補になる。35歳以降は引退確率が上昇し、40歳以降は大幅に上昇する。最大45歳で引退する。重要な場面では「続行」「引退」を選べる。

引退後に次を表示する。

- 現役年数
- 通算主要成績
- 最高年俸・生涯年俸
- タイトル、代表歴
- キャリア年表
- 称号
- Seed

## 17. 暫定値

- 能力初期値と成長量
- 疲労警告80
- 大会、ドラフト、一軍、海外、代表の判定確率
- 特性の保有上限
- 最大現役年数
